# Deferred needs a recheck date

<!-- id: procedural-deferred-needs-a-recheck-date -->
<!-- category: procedural -->
<!-- the memory itself follows; the engine does not rewrite it -->
Open-questions rule (Session 196): deferred items are reviewed in the first session of the day. Nothing sits deferred longer than five sessions without being closed, advanced, or re-deferred with a new dated reason. A question can be visible in the file and invisibly un-carried; a recheck date is the fix.
